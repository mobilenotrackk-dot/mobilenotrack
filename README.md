## 🔒 Privacy & Accuracy

- ✅ Phone numbers are processed **entirely in the browser** — nothing is stored or sent to a server
- ✅ IP lookup services are only called when the user actively uses a feature (e.g. "My IP")
- ✅ No exact real-time location, address, or identity is revealed — **region-level information only**
- ⚠️ India operator detection is an **estimate** based on original number series; due to Mobile Number Portability (MNP), the actual current operator may differ
- 📢 Site uses Google AdSense for ads
