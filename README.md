## 🔒 Privacy & Accuracy

- ✅ Phone numbers are processed **entirely in the browser** — nothing is stored or uploaded by the phone lookup tool
- ✅ IP lookup services are only called when the user actively uses a feature (e.g. "My IP")
- ✅ No exact real-time location, address, or identity is revealed — **region-level information only**
- ⚠️ India operator detection is an **estimate** based on original number series; due to Mobile Number Portability (MNP), the actual current operator may differ
- 📢 Site uses Google AdSense for ads
- ✅ Utility tools process files and text locally in the browser
- ℹ️ DNS, WHOIS/RDAP, IP and related network checks may send the domain or IP entered by the user to the respective third-party service required to provide the result

## 🛠️ Free Utility Tools

The website also provides additional browser-based utilities:

- 📷 **QR Code Generator** — Text/URL, Wi-Fi and Contact (vCard)
- 🗜️ **Image Compressor** — Client-side image compression
- 🎂 **Age Calculator** — Age and next-birthday calculation
- 📄 **Image → PDF** — Multiple images with A4, Letter and Square page options
- 🔍 **PDF Info** — PDF version, size, header and basic metadata checker

### Browser Processing

The utility tools are designed to process files and text directly in the user's browser. Files selected for the QR, image and PDF utilities are not uploaded to Mobile No Track's servers.

The QR generator uses the open-source **qrcodejs** library. Other website functionality also uses open-source libraries and public technical services as described below.
